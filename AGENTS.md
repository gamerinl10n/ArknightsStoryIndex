# Project rules

Read README.md and docs/architecture.md before changes. Preserve Korean/Chinese text and provenance. Never infer addressees from co-occurrence alone. Keep automated candidates separate from reviewed evidence. Never present synthetic dialogue as official. Preserve review history across imports; invalidate stale evidence. Never commit secrets, raw game dumps, or runtime databases. Run unit tests and JavaScript syntax checks. Ship changes via a feature branch and PR; report missing live-data verification explicitly.
