# Arknights Index

명일방주 캐릭터의 **대사·말투·호칭 용례**를 앞뒤 문맥과 함께 찾는 비공식 검색 도구입니다.

[사이트 열기](https://www.arknightsindex.com/) · [사용 설명서](https://www.arknightsindex.com/help?ui=ko) · [패치 노트](https://www.arknightsindex.com/changelog?ui=ko) · [피드백](https://tally.so/r/lb2Lxo)

## 할 수 있는 일

- **인물 하나**: 해당 인물의 대사를 모아 말투와 표현을 살펴봅니다.
- **인물 둘**: 두 번째 인물의 이름·등록 별칭이 포함된 첫 번째 인물의 대사를 찾습니다.
- **표현 검색**: 인물 없이 단어나 문구만 검색하거나, 인물로 결과를 좁힙니다.
- **다국어 검색**: 어느 언어의 단어든 네 언어에서 함께 찾고 페이지 언어를 중심으로 표시합니다. 결과의 언어 버튼으로 다른 언어를 즉시 함께 봅니다. 동일한 명령·분기 구조를 검증한 파일만 연결하며, 미확인 대응과 번역 파일 누락을 구분합니다.
- **문맥 확인**: 앞뒤 대사를 최대 100개씩 확장하고, 작은 물음표에서 출처·행·분기를 확인합니다.
- **검색 주소**: 검색 조건을 주소에 기록해 새로고침과 뒤로 가기에서 복원합니다.

상단 언어를 바꾸면 화면과 대사 언어가 함께 전환됩니다. 검색어는 한국어·중국어·일본어·영어 원문에서 함께 찾습니다. 검증된 대응이 없으면 검색된 언어를 표시합니다. 검색창에 붙는 자동완성, 다크·라이트 모드와 새 버전 알림을 제공합니다.

> 두 인물 검색은 이름이 포함된 대사를 찾으며, 같은 분기에서 상대 인물의 발화가 가까운 결과를 우선합니다. 이는 직접 대화를 확정하는 분류가 아닙니다. 직접 호칭인지, 다른 사람을 언급하는 말인지는 원문과 문맥으로 판단하세요. 대명사나 생략된 이름은 검색에서 빠질 수 있습니다.

## 빠른 시작

Python 3.12 이상과 Git이 필요합니다. 원본 수집에는 네트워크와 충분한 디스크 공간이 필요합니다.

```sh
git clone https://github.com/gamerinl10n/Arknights_Index.git
cd Arknights_Index
python -m pip install -r requirements.txt
python sync.py
python build_portraits.py
python app.py
```

<http://127.0.0.1:8000>에서 실행됩니다. 원본과 생성 DB는 `data/`에 보관하며 Git에 커밋하지 않습니다.

## 데이터와 한계

[ArknightsAssets/ArknightsGamedata](https://github.com/ArknightsAssets/ArknightsGamedata)의 공개 원본을 자체 파서로 변환하고, 원본 SHA·파일 경로·줄 위치를 보존합니다. 공식 캐릭터 ID로 언어별 이름을 연결합니다. 직접 게임 리소스 다운로드는 아직 구현하지 않았습니다.

- 한국 서버 공개 범위는 같은 경로의 한국어 파일 존재 여부로 판단하는 **근사치**입니다.
- 대사·다중행·내레이션·자막·스티커 텍스트·선택지를 검색합니다. 화자를 명시하지 않은 원문은 이름 없음으로 표시합니다. 미지원 명령·튜토리얼 등은 남아 있으므로 결과가 없다고 용례가 없다는 뜻은 아닙니다.
- 검색어는 서버로 전송되며 요청·공유 URL에 포함됩니다. [개인정보 안내](https://www.arknightsindex.com/privacy?ui=ko)를 참고하세요.
