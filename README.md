# Arknights Story Index

명일방주 화자별 대사와 인물 간 호칭 용례를 조사하는 비공식 도구. 첫 구현 단계입니다.

## 실행

Python 3.11+, Git이 필요합니다. 외부 Python 패키지는 필요하지 않습니다.

```sh
python sync.py
python app.py
```

http://127.0.0.1:8000 에서 검색합니다. 첫 동기화는 중국어·한국어 스토리를 내려받으므로 시간이 걸립니다. 원본·DB는 git에 넣지 않습니다. `data/`를 영구 디스크에 두고 별도로 백업하세요.

이미 내려받은 원본을 가져올 수도 있습니다.

```sh
python app.py --import-root /path/to/ArknightsGamedata --revision <commit-sha>
```

관리자 검토는 `ASI_ADMIN_TOKEN` 환경 변수에 32자 이상의 임의 비밀값을 설정한 뒤 서버를 시작하고, 화면에서 같은 토큰을 입력합니다. 토큰은 브라우저 메모리에만 유지됩니다. 미설정 시 검토 쓰기는 차단됩니다. 공개 운영 시 HTTPS 역방향 프록시, 요청 제한, 영구 디스크 및 백업이 필요합니다. 현재는 단일 운영자 토큰 인증이며 OAuth 로그인은 아직 없습니다.

## 현재 동작

- A만 입력: 화자 표기 부분 일치로 대사 검색.
- B도 입력: B의 이름이 본문에 포함되거나 B에 대한 검토 기록이 있는 대사 검색. 자동으로 상대를 확정하지 않습니다.
- 직접 호칭 / 제삼자 지칭 / 관련 대사 / 후보 제외를 관리자가 기록.
- 원문·화자·분기 정보가 바뀌면 검토가 재검토 상태로 전환. 검토 이력과 원본 스냅샷은 별도 보존.
- 중국어는 기본적으로 같은 경로의 한국어 스토리가 존재하는 범위만 표시. 이는 한국 서버 공개 여부의 근사치이며 정확한 공개 일정 메타데이터는 후속 작업.
- 앞뒤 원본 줄과 분기 표기를 표시. 물리적 인접 대사가 같은 대화 분기에 속한다고 가정하지 않음.
- 다른 언어 같은 줄 위치는 대응 후보로만 표시.

## 데이터와 한계

`ArknightsAssets/ArknightsGamedata` 원본 TXT를 자체 파서로 변환합니다. ASTR의 가공 JSON에 의존하지 않습니다. 수집처 commit SHA를 기록하고 원문을 보존합니다. 가져오기 전체를 먼저 파싱한 후 트랜잭션으로 반영하므로 실패 시 기존 검색 데이터는 유지됩니다.

현재 파서는 name/multiline 대사만 추출하는 초기 버전입니다. 자막·선택지·다중행 병합, 인물 별칭/정체 매핑, 정확한 분기 그래프, 원문 줄 이동 시 검토 재연결, 삭제 스토리 처리, 대규모 검색 성능 개선이 남아 있습니다. 데이터가 없는 것을 공식 용례가 없다는 뜻으로 해석하면 안 됩니다. 실제 전체 데이터 수집 및 M3→켈시 정확도 검증은 별도로 필요합니다.

게임 리소스 직접 다운로드는 아직 구현하지 않았습니다. 설계는 `docs/architecture.md`를 확인하세요. 코드와 게임 원문에 대한 권리는 구분합니다. 제삼자 코드 또는 데이터를 재배포할 때 해당 조건을 확인하세요.

## 검색 정확도 개선

화자는 부분 문자열 대신 정확한 표기로 검색합니다. `characters.json`에 언어별 이름과 검색용 별칭을 추가할 수 있습니다. 현재 `M3 → Mon3tr`, `켈시 ↔ 凯尔希`를 연결했습니다. 정체가 불명확한 물음표 화자나 합동 화자는 자동 병합하지 않습니다.

대상별로 제외한 후보는 같은 원문에서 숨기고, 원문이 바뀌면 다시 검토 후보가 됩니다. 직접 호칭/지칭 검토에는 원문에 존재하는 표현이 필요합니다. 100개 이상 적재된 DB에서 대사가 20% 이상 감소하면 가져오기를 차단합니다. 작은 DB는 이 감소 검사를 적용하지 않습니다. 삭제 반영과 누락 파일 검사는 여전히 후속 작업입니다.

`/api/status`에서 마지막 성공한 수집의 버전, 파일 수, 추출 대사 수 및 미처리 일반 텍스트 줄 수를 확인할 수 있습니다. 미처리 일반 텍스트에는 내레이션과 설명 파일도 포함되므로 이를 대사 누락률로 해석하지 않습니다.
