# 원문·번역 대응 1차 조사

2026-10-23. 원본: ArknightsAssets/ArknightsGamedata, 고정 SHA `db6f9ef8046ad17dbebe3ff1d0dd88844a5bc78c`.

## 확인 범위와 결과

초기 6개(메인 3·오퍼레이터 기록 2·이벤트 1)에 메인과 오퍼레이터 기록 목록의 분산 표본 16개를 추가했다. 총 22개 중국어 파일, 텍스트 3,591행을 같은 경로의 한국어·일본어·영어와 비교했다. 무작위 대표 표본은 아니며 전 코퍼스 검사는 아니다. 원문 덤프는 저장소에 추가하지 않았다.

| 대상 | 확인 파일 | 명령 구조·텍스트 수 동일 | 공식 ID로 양쪽 화자 확인 | 그중 화자 ID 불일치 |
| --- | ---: | ---: | ---: | ---: |
| 한국어 | 22 | 22 | 1,723행 | 0 |
| 일본어 | 22 | 22 | 1,723행 | 0 |
| 영어 | 22 | 22 | 1,723행 | 0 |

`[name]` 등의 번역 텍스트·화자 이름·선택지 문구를 제외하고 명령 순서와 비번역 속성을 비교했다. 동일 명령 구조와 텍스트 수를 만족하는 구간에서만 공식 화자 ID를 대조했다. 이 표본에서는 물리 행도 일치했지만, 물리 행을 번역 대응의 근거로 삼지는 않는다.

대부분의 대사 명령에는 고유 대사 ID가 없었다. 텍스트 속성 `id`가 있는 사례는 sticker 3개였고 `st1` 한 값이 재사용됐다. 이를 범용·언어 공통 대사 ID로 쓸 수는 없다.

## 해석과 한계

이 수치는 **구조적 연결 가능성**이며 의미상 번역 정확도·대응 정확도·전 코퍼스 연결률이 아니다. 22개 중 구조 불일치나 미공개 번역 파일이 없었으므로 삽입·삭제·다대다 번역과 미공개 사례에 대한 실제 데이터 검증은 남아 있다. 화자 ID를 확인할 수 없는 NPC·서술문·선택지에 대한 의미 검수도 별도로 필요하다.

안전한 첫 제공 범위는 전체 명령 구조·분기 속성·텍스트 수가 일치하고 알려진 화자에 충돌이 없는 파일의 일대일 연결 후보이다. 이를 서비스에 노출하기 전에는 의미 대조 표본 검수와 전 코퍼스 통계가 필요하다. 구조가 다른 파일을 억지로 줄 번호로 연결하지 않는다. 다대다 정렬은 후속으로 분리한다.

## 재현

```sh
python scripts/audit_alignment.py /path/to/ArknightsGamedata --revision db6f9ef8046ad17dbebe3ff1d0dd88844a5bc78c --paths /path/to/sample-paths.json
```

sample-paths.json은 alignment-sample-audit.json의 files[].path 목록이다. 스크립트는 네트워크 접근·DB 변경 없이 명령 구조·개수·SHA-256만 출력하며 대사 원문은 출력하지 않는다. 전체 코퍼스는 --paths 없이 조사할 수 있지만 이번에는 실행하지 않았다.

다음 개발 기준: 전 코퍼스 구조 통계 → 불일치·미공개 사례 표본 확장 → 의미 대조 검수 → 파일/분기 단위 검증된 대응 인덱스 생성 → 중국어 검색과 선택 언어 번역 동시 표시. 이 보고서가 대조 검색 기능의 출시를 의미하지 않는다.
