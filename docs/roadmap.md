## 원문·번역 대조 검색: 첫 제공 범위 구현

요청: 기본 검색은 선택 언어 결과만 표시한다. 선택적으로 중국어 원문과 현재 화면 언어의 공식 번역을 함께 표시한다. 한국어 화면에서 중국어 `你好`를 원문에서 검색하면 해당 원문과 대응하는 한국어 번역을 결과로 확인할 수 있어야 한다. 검색어 자체를 번역해 재검색하는 기능이 아니다.

### 제안하는 화면

- 기본은 기존 단일 언어 검색. 별도의 `원문·번역 대조` 모드를 선택하면 검색 언어 기본값을 중국어로, 대조할 번역 언어를 현재 화면 언어로 둔다. 중국어 화면은 번역 언어를 한국어·일본어·영어 중에서 명시적으로 선택한다.
- 기존 대사 언어 선택기는 검색할 언어를 결정한다. 대조 모드에서 한국어 등을 선택하면 번역에서 찾고 중국어 원문을 함께 표시하는 역방향 검색도 가능하게 설계한다.
- 중국어 문구를 한국어 기본 검색에 입력했다고 임의로 검색 대상을 바꾸지 않는다. 한자는 일본어 등과 공유되므로 글자만으로 검색 의도를 확정할 수 없다. 결과가 없을 때 `중국어 원문에서 검색` 동작으로 대조 모드 재검색을 제안할 수 있다.
- 결과 카드는 중국어 원문 / 선택 번역을 위아래로 표시한다. 검색어는 실제 일치한 언어에서만 강조한다. 모바일과 문맥 확장에서도 짝을 유지한다.
- 번역 미공개는 `번역 미공개`, 대응 불명확은 `대응 번역을 확인하지 못함`으로 구분한다. 원문만 있는 결과의 포함 여부는 공개 범위 설정에 따른다. AI 번역으로 빈칸을 채우지 않는다.

### 구현 전 확인할 데이터 과제

현재 lines.id와 ordinal은 언어별 물리 행 위치이며 branch에도 물리 행 번호·현지화 속성이 들어간다. 동일 파일·동일 행 번호를 번역 짝으로 사용할 수 없다. 예전에 제거한 같은 줄 위치 후보 UI를 복원하지 않는다.

1. 같은 스토리 파일의 원문 스크립트를 비교해 언어 공통의 명시 ID가 있는지 먼저 조사한다. 현재 적재 필드에는 언어 공통 대사 ID가 없다.
2. 명시 ID가 없다면 번역 텍스트를 제외한 명령·분기·장면 경계와 공식 화자 ID, 발화 순서를 이용해 구간을 정렬한다. 분기 식별은 원시 branch 문자열의 동일 비교로 대신하지 않는다.
3. 한 문장 대 여러 문장, 삽입·삭제·분기 차이를 처리할 다대다 대응 테이블을 빌드에서 생성한다. 짧은 인사말의 의미 유사성만으로 연결하지 않는다. 불확실한 짝은 확정 번역으로 노출하지 않는다.
4. 언어·스토리 유형별 표본으로 연결 정확도와 누락률을 측정한 뒤 제공 범위를 정한다. 각 언어 원본 SHA·경로·행과 정렬 방법/버전을 보존한다. 원문 또는 번역이 갱신되면 해당 짝을 재검증한다.
5. 원문에서 검색·정렬·페이지 제한한 후 저장된 대응 테이블을 한 번에 조회한다. 행마다 별도 네트워크/정렬을 실행하지 않는다. 단일 언어 검색은 대조 조회를 하지 않는다. 원문 일치 수와 번역 연결 수를 구분하고 다대다 연결을 카드 단위로 묶는다.
6. 배포 DB 용량, 선행 스토리 공개 범위, 검색·번역 언어·대조 모드의 URL 복원, 문맥의 대응/미대응 표시를 함께 검증한다.

권장 진행: 먼저 실제 원문 표본으로 대응 가능성을 조사하고 정확도·범위를 보고한다. 그 결과를 사용자와 확인한 뒤 대조 검색을 다음 개발 묶음에 포함한다. 표본 조사와 결과 보고까지 진행하도록 사용자가 승인했다. 후속 진행 승인으로 전체 원본을 검사하고 구조가 일치하는 파일 범위에서 대조 검색을 구현했다.


## 이번 개발 묶음

- 언어 전환 스플래시: L10ndiff의 CSS/SVG 방식과 leave(380ms) → 이동 → enter(300ms) 구조를 참고. 기존 토끼 PNG를 몸·양쪽 귀의 CSS 레이어로 나누어 튕김과 지연된 귀 흔들림을 적용한다. GIF를 추가로 다운로드하지 않는다. reduced-motion, 새 탭 열기, 저장소 제한, 뒤로 가기와 이동 실패 복구를 검증한다.
- 중앙 로고 제거. 검색 버튼 옆에 네 언어의 입력 지우기 버튼을 두고 검색 문구·인물을 비운다. 선택 언어·선행 스토리 설정은 유지한다. 결과 화면에서 지우면 빈 홈으로 이동하고 새로고침에 이전 검색어가 복원되지 않게 한다.
- 원문 대응 조사: 고정 SHA의 22개 스토리, 중국어 대사 3,591행 및 한·일·영어 파일을 비교. 결과와 범위는 alignment-feasibility.md, 수치는 alignment-sample-audit.json에 기록.

## 추가 참고: 언어별 음성 기록

사용자 참고 URL: https://prts.wiki/w/THRM-EX/语音记录

- 대조 검색 결과의 언어별 표시와 음성 재생 UI 참고 대상으로 기록. 음성 기능 구현은 아직 승인된 이번 묶음에 포함하지 않는다.
- 음성을 후속 기능으로 검토할 때는 오퍼레이터 음성 기록과 스토리 대사를 구분한다. 음성 파일 존재·원본 출처·클립 식별자·표시 대사와의 정확한 연결을 조사한 뒤 지원 범위를 정한다. 모든 스토리 대사에 음성이 있다고 가정하지 않는다.
- 기본 자동 재생은 하지 않고 사용자가 재생 버튼을 누를 때만 파일을 불러오는 방향을 검토한다. 위키의 음성 URL을 그대로 외부 재생 링크로 사용하는 것으로 확정하지 않는다.

## 후속 진행 결과

- 스플래시의 네모 카드 배경·테두리·그림자를 제거하고 토끼만 표시한다.
- 전체 원본의 구조 검사와 대응 인덱스를 추가하고 중국어 ↔ 한국어·일본어·영어 선택 대조 검색 및 문맥 대조를 구현한다. 구조 불일치·화자 충돌 파일과 분할/병합 번역은 제외한다. 세부 범위는 alignment-feasibility.md 및 alignment-full-summary.json에 기록한다.
- PRTS 음성 기능, 검색 복귀 상태, 일반 단어 검색 성능 개선 등 기존 미구현 후보는 유지한다.


## 사용자 수정 확정: 언어 통합 검색과 결과 표시 (2026-10-23)

이 항목이 이전의 독립 검색 언어·대조 모드 계획을 대체합니다. 검색창의 언어 선택과 대조 체크박스를 제거합니다. 단어는 네 언어에서 함께 찾고 검증된 같은 대사를 중복 제거한 뒤 페이지 언어를 주 대사로 표시합니다. 결과의 언어 버튼으로 다른 언어를 여러 개 켜고 끄며 재검색하지 않습니다. 페이지 언어는 항상 표시합니다. 대응 미확인일 때는 검색된 언어와 안내를 표시하고 임의 번역은 넣지 않습니다. 음성 재생은 여전히 후속 조사 항목입니다.
